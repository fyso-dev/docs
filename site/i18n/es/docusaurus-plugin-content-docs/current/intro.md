# Documentación de Fyso

Fyso es una plataforma para construir aplicaciones de negocio usando entidades, reglas de negocio y automatizaciones. Puede operarse desde un panel web o mediante herramientas MCP (Model Context Protocol) para agentes de IA.

## Inicio rápido

1. [Primeros pasos](getting-started/quick-start.md) — Tu primera app en 5 minutos
2. [Conceptos clave](getting-started/concepts.md) — Tenants, entidades, campos, registros, reglas
3. [Configurar MCP](getting-started/mcp-setup.md) — Conectar agentes de IA a Fyso

Esta documentación sirve a dos audiencias:

- **Agentes de IA usando MCP** — Nombres exactos de herramientas, parámetros, tipos y respuestas esperadas
- **Humanos usando el panel web** — Guías claras con ejemplos y flujos de trabajo
